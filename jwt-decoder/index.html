    Warum keine Signaturprüfung?
    

      Eine echte Prüfung bräuchte den geheimen oder öffentlichen
      Schlüssel, mit dem das Token signiert wurde — den hat ein
      reines Anzeige-Tool nie. Header und Payload sind bei einem JWT
      ohnehin nur Base64url-codiert, nicht verschlüsselt, jeder kann
      sie mitlesen; nur die Signatur beweist, dass niemand sie
      unterwegs verändert hat.
